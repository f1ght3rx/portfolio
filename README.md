# Портфолио

Простой адаптивный одностраничный сайт-портфолио на чистом HTML/CSS/JS.

## Что уже готово

- Главный экран с позиционированием и CTA
- Разделы: Обо мне, Работы, Опыт, Навыки, Образование, Контакты
- Адаптивное меню для мобильных
- Базовая структура для быстрого деплоя на VPS

## Что нужно обновить перед публикацией

1. В `index.html` обновить email и ссылки на GitHub/Telegram.
2. В блоке `Работы и проекты` при необходимости заменить карточки на реальные проекты:
   - название;
   - описание;
   - стек;
   - ссылка на GitHub/демо.

## Локальный запуск

Вариант 1: открыть `index.html` в браузере.

Вариант 2 (рекомендуется):

```bash
python -m http.server 8080
```

Потом открыть [http://localhost:8080](http://localhost:8080).

## Деплой на VPS

1. Скопировать файлы проекта на сервер.
2. Настроить Nginx/Apache на выдачу статических файлов.
3. Проверить, что корнем сайта является папка с `index.html`.
